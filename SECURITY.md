# Security Policy

## Supported versions

Only the latest commit on the default branch (`main`) receives security fixes.
There are no maintained release branches.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private advisory form:
https://github.com/hellpuffyt/bundle-forensics/security/advisories/new

Do not open a public issue for a suspected vulnerability, and never include real
secrets, tokens, or production payloads in a report; use synthetic values.

Please include the affected version or commit, a minimal reproduction, and the
impact you observed. Reports are handled on a best-effort basis by a single
maintainer; there is no bug bounty.
